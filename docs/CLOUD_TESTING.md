# ZSMS Cloud Staging & Android APK Testing Guide

This guide explains how to download the automated Android APK artifact generated by GitHub Actions, install it onto your physical Android phone, connect it to the Dokploy environment (`https://sms-api.ztechai.us`), and verify real cellular SMS sending and receiving.

**No Android Studio, JDK, or command-line SDK tools are required on your Windows computer.**

---

## 1. Prerequisites
* A physical Android smartphone (Android 8.0 through Android 14) with an active physical SIM card.
* An active internet connection on your phone (Wi-Fi or cellular data).
* Access to the ZSMS GitHub repository.
* The ZSMS environment deployed on Dokploy (`https://sms.ztechai.us`).

---

## 2. Step-by-Step APK Download from GitHub Actions

1. Open your web browser on your PC or Android phone and navigate to your **ZSMS GitHub Repository**.
2. Click on the **Actions** tab at the top of the repository:
   ```text
   GitHub Repo -> [ Actions ]
   ```
3. In the left sidebar, select the workflow named:
   **`ZSMS Android APK Build & Artifact Upload`**
4. Click on the most recent run (indicated by a green checkmark ✅).
5. Scroll down to the **Artifacts** section at the bottom of the summary page.
6. Click on the artifact named:
   **`ZSMS-Android-Debug`**
   *(Your browser will download a ZIP file named `ZSMS-Android-Debug.zip` containing `app-debug.apk`).*

---

## 3. Installing the APK on Your Physical Android Phone

### Option A: Direct Download on Mobile Browser
If you opened GitHub Actions on your phone's browser, download `ZSMS-Android-Debug.zip`, extract it using your phone's Files app, and tap `app-debug.apk` to install.

### Option B: Transfer from Windows PC to Phone
1. Extract `ZSMS-Android-Debug.zip` on your Windows computer to reveal `app-debug.apk`.
2. Transfer `app-debug.apk` to your phone using any method:
   * **USB Cable**: Connect phone to PC, drag `app-debug.apk` into your phone's `Download` folder.
   * **Google Drive / Dropbox / OneDrive**: Upload from PC, download on phone.
   * **Nearby Share / Quick Share**: Send wirelessly from Windows to Android.
   * **Messaging app**: Send file to yourself via WhatsApp Web or Telegram.
3. On your Android phone, open the **Files** or **My Files** app, navigate to `Downloads`, and tap `app-debug.apk`.
4. If Android displays: *"For your security, your phone is not allowed to install unknown apps from this source"*:
   * Tap **Settings**.
   * Toggle on **Allow from this source**.
   * Tap **Back** and tap **Install**.
5. Once installation finishes, tap **Open**.

---

## 4. Granting Telephony & Notification Permissions

When ZSMS launches for the first time:
1. Tap the **Grant SMS Permissions** button on the main screen.
2. Accept the Android system permission prompts:
   * **Send and view SMS messages**: Tap **Allow** *(Enables cellular radio transmission)*.
   * **Send and receive SMS messages**: Tap **Allow** *(Enables inbound SIM reply detection)*.
   * **Make and manage phone calls / Phone state**: Tap **Allow** *(Allows detecting cellular carrier name & SIM slot)*.
   * **Notifications** (Android 13+): Tap **Allow** *(Ensures foreground service status bar notification remains visible)*.
3. Battery Optimization (Crucial for background operation):
   * Open Android **Settings > Apps > ZSMS > Battery**.
   * Select **Unrestricted** (prevents Android OS from freezing the WebSocket connection during sleep).

---

## 5. Configuring Server URL

1. In the ZSMS app, tap **Server Settings**.
2. Verify that the **Server URL** is configured to the ZSMS API:
   ```text
   https://sms-api.ztechai.us
   ```
   *(It defaults to `https://sms-api.ztechai.us`).*
3. Tap **Test Server Connection**.
4. You should see a green success message:
   ```text
   CONNECTED! Server responded with HTTP 200
   ```
5. Tap **Save Configuration**.

---

## 6. Pairing Phone with Web Dashboard

1. On your PC or laptop, open your browser and go to the Web Dashboard:
   ```text
   https://sms.ztechai.us
   ```
2. Log in (or create an account if this is the first run).
3. Navigate to **Phone Gateways** (`/phones`) and click the **Pair New Phone** button.
4. A modal will display a single-use 6-digit PIN (e.g. `492 817`) with a 10-minute countdown timer.
5. In the ZSMS Android app:
   * Tap **Pair Gateway Device**.
   * Enter the 6-digit PIN displayed on the web dashboard.
   * Tap **Connect & Authenticate**.
6. The app will securely claim the session, receive an encrypted device API key, and store it in Android Keystore `EncryptedSharedPreferences`.
7. **Verification**:
   * In the app, the connection badge turns green: **ONLINE (CONNECTED)**.
   * In the status bar, the persistent notification shows: *"Gateway ONLINE (Active cellular bridge)"*.
   * On the Web Dashboard (`/phones`), your phone appears with its SIM carrier, battery level, and live **ONLINE** status!

---

## 7. Executing Real Cellular SMS Tests

### Test 1: Outbound Cellular SMS (Web -> SIM -> Real Handset)
1. On the Web Dashboard, go to **Messages** (`/messages`).
2. Click **Send Real SMS**.
3. Select your paired Android phone from the gateway dropdown.
4. Enter an external recipient mobile phone number (in E.164 format, e.g. `+1234567890`).
5. Enter message text:
   ```text
   ZSMS cellular verification 001
   ```
6. Click **Dispatch Real Cellular SMS**.
7. **Observe Real Delivery**:
   * The Go API immediately pushes the message over the secure WSS WebSocket (`wss://sms-api.ztechai.us/api/v1/gateway/ws`).
   * The Android app receives the command and calls `SmsManager.sendMultipartTextMessage`.
   * The physical SIM transmits the SMS through the cellular carrier cell tower.
   * The recipient handset physically vibrates and displays the message!
   * The Web Dashboard status transitions: `processing` -> `sent` -> `delivered`.

### Test 2: Inbound Cellular SMS (Real Handset -> SIM -> Web)
1. From the recipient handset, reply to the text message:
   ```text
   ZSMS inbound test reply 001
   ```
2. **Observe Real Reception**:
   * The Android baseband radio receives the SMS.
   * Android `SmsReceiver` intercepts `Telephony.SMS_RECEIVED`, parses the PDU, and POSTs to `/api/v1/android/messages/inbound`.
   * On the Web Dashboard, open **Two-Way Conversations** (`/conversations`).
   * The inbound message appears in the chat stream in real time!

## 8. Troubleshooting Connections

* **"ERROR: Unable to resolve host"**: Check that the phone has working cellular data or Wi-Fi. Confirm `sms-api.ztechai.us` DNS records are active in Cloudflare.
* **"UNREACHABLE: Server returned HTTP 502/503"**: The Dokploy containers may still be starting. Verify in Dokploy that `zsms-staging-api` (or `zsms-prod-api`) is healthy.
* **"Pairing code invalid or expired"**: Pairing codes are valid for 10 minutes and can only be used once. Click **Pair New Phone** on the web dashboard to generate a fresh code.
* **Phone goes OFFLINE after screen lock**: Go to phone **Settings > Apps > ZSMS > Battery** and set to **Unrestricted**.
