# ZSMS Test Suite

## Structure

* **Backend Unit Tests**: Located in `backend/tests/` (testing config parsing, secret masking, health check handlers).
* **Frontend Tests**: Configured in `web/` using TypeScript checking (`npm run typecheck`).
* **Android Unit Tests**: Configured in `android/app/src/test/` using JUnit.
* **E2E & Integration Tests**: Planned for Stage 20.
